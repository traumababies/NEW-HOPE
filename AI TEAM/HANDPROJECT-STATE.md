## Backend — the two containers (owner decision, 2026-09-13, account godzilla1126)

- **bunbuns** (`azure_storage_container`) — cataloged Library assets only. Promoted, owner-approved media lives here permanently.
- **Ephemera** (`azure_storage_container_ephemera`) — ALL scout search results + Studio candidates. Holds things while you decide; unpicked candidates expire naturally, never feed the Library directly.
- Flow: drop/search → Ephemera (provisional name) → commit → chosen originals get full metadata + UUID into **bunbuns** + Cataloger queue; derivatives queue with the Media Editor instead. Config lives in `app\config.py`.
- One identifier only (fixed 2026-09-14): `app\studio_routes.py` now reads `settings.azure_storage_container_ephemera` instead of hardcoding `"ephemera"`, and the config default is lowercase `ephemera`. Azure Blob container names allow lowercase letters/digits/hyphens only — a capital `Ephemera` is an invalid resource name that fails in Azure while looking fine on case-insensitive Windows paths.

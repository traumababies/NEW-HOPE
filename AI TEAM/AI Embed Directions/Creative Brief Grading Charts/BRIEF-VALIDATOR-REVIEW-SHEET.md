# Creative Brief Validator Review Sheet

## Purpose

The Brief Validator checks whether a Creative Director brief is complete, structurally valid, internally consistent, and safe to hand to Creative Grader, Content Scout, or Media Editor.

This review is primarily deterministic. It should reject incomplete or contradictory briefs without judging artistic quality.

## Decision

- [ ] PASS
- [ ] PASS WITH WARNINGS
- [ ] BLOCKED

- [ ] Start time.
- [ ] End time.

- [ ] Visible action.
- [ ] Setting or environment.
- [ ] Camera framing.
- [ ] Camera movement.
- [ ] Lighting.
- [ ] Color or texture.
- [ ] Transition.
- [ ] Audio.
- [ ] Voiceover or dialogue.
- [ ] On-screen text.
- [ ] Required search evidence.
- [ ] Rejection conditions.
- [ ] Fallback option.

Reject vague instructions when they are the only instruction:

- [ ] No unsupported “make it cinematic” direction.
- [ ] No unsupported “make it beautiful” direction.
- [ ] No unsupported “show growth” direction.
- [ ] No unsupported “use emotional music” direction.

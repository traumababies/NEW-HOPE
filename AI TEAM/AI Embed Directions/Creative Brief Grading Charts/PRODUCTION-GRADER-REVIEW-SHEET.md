# Production Grader Review Sheet

## Purpose

The Production Grader determines whether the brief can be sourced, edited, generated, licensed, and delivered without unnecessary credit waste.

It answers:

> Can Content Scout and Media Editor execute this brief with acceptable risk?

## 7. Candidate acceptance rules — ____ / 10

### Accept when

- [ ] Required subject is visible.
- [ ] Required action occurs.
- [ ] Required framing is available.
- [ ] Color and mood match.
- [ ] Duration is adequate.
- [ ] Crop is safe.
- [ ] License is acceptable.
- [ ] No prohibited content appears.
- [ ] Asset supports the narrative purpose.

### Reject when

- [ ] Required action is only implied.
- [ ] Subject is too small.
- [ ] Shot cannot survive vertical cropping.
- [ ] Mood conflicts with the weekly bible.
- [ ] Footage looks staged when authenticity is required.
- [ ] Footage is too generic.
- [ ] License is unclear.
- [ ] Faces, hands, text, or objects are defective.
- [ ] Shot requires excessive repair.
- [ ] Shot cannot be edited at the planned time.

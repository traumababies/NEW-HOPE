# Copy Grader Review Sheet

## Purpose

The Copy Grader independently evaluates whether captions, hashtags, alt text, disclosures, and platform adaptations are accurate, useful, natural, and aligned with the completed media.

The Copywriter must not grade her own copy.

Score each category from 0 to 5:

- **0** = absent or unacceptable
- **1** = very weak
- **2** = weak
- **3** = acceptable
- **4** = strong
- **5** = excellent

## Automatic copy failures

Block the copy regardless of score if:

- [ ] It invents a material fact.
- [ ] It makes an unsupported health, scientific, financial, product, or performance claim.
- [ ] It hides a required commercial disclosure.
- [ ] It exposes private personal information.
- [ ] It uses misleading clickbait.
- [ ] It claims an endorsement, personal experience, or result that is not verified.
- [ ] It uses inaccurate product ingredients or benefits.
- [ ] It uses rights-sensitive attribution incorrectly.
- [ ] It contains a serious factual or grammatical error.
